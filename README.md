# Клуб Кулибиных — демонстрационный прототип

Простой HTML, CSS и JavaScript, без сборки и зависимостей. Готовый сайт — `index.html` в корне репозитория. Редактор расписания — `расписание/schedule-editor.html`. Оба HTML-файла самостоятельные. Раздельные исходники основного сайта находятся в `dist/`.

Для совместной работы сайта и редактора раздайте корень репозитория одним статическим сервером. Так изменения расписания и текстов будут видны в карточках детей в этом же браузере.

Демо-вход: admin / admin. Это интерфейсная имитация входа, а не защита данных. Существующая система авторизации не подключена.

Все ФИО, операции и товары вымышлены. Счёт вычисляется по истории операций. Товары и витрины сохраняются в localStorage текущего браузера; общей базы данных и синхронизации между устройствами нет. Только одна витрина опубликована. Удаление товара убирает его из всех витрин. PNG/JPG/WebP загружаются локально (до 3 МБ); при переполнении браузерного хранилища показывается ошибка, изменения не сохраняются.

В разделе счёта сначала отображается только поиск. Для демонстрации введите Петров, Иванов или Сидоров и выберите полное ФИО из результатов. Счёт, посещения и история появляются после выбора.

В витрине 16 примеров товаров. Витрина отображается только карточками. Новые примеры добавляются к старым сохранённым данным один раз, без сброса внесённых изменений.

Остатки товаров не учитываются: поля количества нет в карточках, формах, списках и новых записях. При открытии обновлённой версии ранее сохранённые остатки удаляются из данных браузера без сброса товаров и витрин.

Полные ФИО детей сохранены в данных и доступны для поиска. В результатах, выбранном значении поля и карточке показываются только фамилия, первая буква имени и постоянный эмоджи (например, «Петров А 🦾»). Эмоджи хранится в записи ребёнка; у детей с одинаковой фамилией и первой буквой имени он должен различаться.

Календарь в карточке ребёнка использует расписание из `расписание/schedule-editor.html`: выбранные дни недели, исключённые даты, ДЗ, подтверждения начислений из чат-бота и отработки. Бонус задаётся отдельно для группы и начисляется после закрытия всех учитываемых дат в последний день расписания; поздняя отработка тоже засчитывается. Повторное открытие не дублирует бонус. История и баланс показывают те же начисления.

`dist/attendance-model.js` содержит модель личной карточки с теми же правилами расчёта, что у редактора расписания. Оба экрана читают `culibin-schedule-prototype-v1` из localStorage. При размещении на одном сайте изменения из редактора видны в карточке ребёнка, в том числе в соседней вкладке. При прямом открытии разных HTML-файлов браузер может хранить их данные раздельно. Демо-данные создаются только при отсутствии сохранённого расписания.

В одном календаре сразу показаны все занятия ребёнка из всех его расписаний. Можно выбрать месяц и нажать на дату для просмотра деталей. Если на одну дату приходятся несколько занятий, они учитываются отдельно; отметка 1/2 показывает частичное выполнение. Общий прогресс и сумма наград объединены для просмотра, а бонусы продолжают начисляться отдельно для каждой группы. Это просмотр: посещения, ДЗ и отработки редактируются в панели администратора. Названия групп и полные ФИО в карточке не отображаются. Время определяется в Asia/Vladivostok.

В редакторе расписания рядом с бонусом сохраняются «Заголовок» и «Контент» мотивационного блока отдельно для каждой группы. В контенте поддерживаются переносы строк и выделение `**жирным**`; HTML отображается как обычный текст. Пустой контент сохраняет автоматическую подсказку по прогрессу. Предпросмотр показывает текст во время редактирования. У ребёнка с несколькими группами одинаковые настройки объединяются в один блок, разные тексты показываются над общим календарём.
